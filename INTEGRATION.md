# Боевая интеграция СТО и 1С

## 1. Что подготовить

На компьютере агента, в `C:\Install`:

- `AvtoPult-OneCAgent-windows-x64.zip`;
- `AvtoPult-OneCAgent-windows-x64.zip.sha256`;
- `install-package.ps1`.

Использовать пакет с `configure-mappings.ps1`.

Для специалиста 1С:

- каталог `one-c-extension-source` из пакета агента;
- Конфигуратор;
- доступ администратора к базе и серверу её веб-публикации;
- отдельную копию базы для сборки и проверки.

---

# Действия специалиста 1С

## 2. Подготовить расширение

В Конфигураторе копии базы:

1. Открыть «Конфигурация → Расширения конфигурации».
2. Создать расширение `AvtoPult`.
3. Создать объекты из `extension-project-manifest.json`. Поля регистров описаны в файлах `*-METADATA.md`.
4. Загрузить код модулей из `src`.
5. Настроить роли, HTTP-сервис и подписки на события по описаниям комплекта.

## 3. Подключить печать счёта

Это доработка кода, а не переключатель настройки.

В модуле `AvtoPultСчета`, функции `Создать`:

1. Сохранить проверку запроса и обработку повторной готовой попытки.
2. Вызвать `Подготовить(Payload)` для создания или получения счёта.
3. Получить штатную печатную форму этого счёта средствами установленной КА2.
4. Передать полученный `ТабличныйДокумент`:

```bsl
AvtoPultСчета.ПринятьPDF(
    СсылкаСчета,
    Payload.requestAttempt,
    ТабличныйДокумент
);
```

5. Возвращать успех только после сохранения PDF в очередь.
6. При ошибке откатывать весь запрос. Внутренние функции не должны самостоятельно фиксировать транзакцию.

Штатную процедуру печати определить по модулю менеджера `СчетНаОплатуКлиенту` установленной КА2.

## 4. Настроить документы и привязки

### Заказы

1. Создать для каждой СТО отдельный непроведённый заказ-образец.
2. Заполнить организацию, подразделение, соглашение, валюту, склад, цены, НДС и порядок расчётов.
3. В регистре `AvtoPultПрофилиСтанций` связать идентификатор СТО `StationId` с заказом `ОбразецЗаказа`.
4. Заполнить связи:
   - `AvtoPultКлиенты`: клиент СТО → партнёр и контрагент 1С;
   - `AvtoPultАвтомобили`: автомобиль СТО → автомобиль 1С.
5. Проверить создание новых клиентов и автомобилей. Если они должны создаваться автоматически, реализовать этот путь в адаптере.

Текущий адаптер рассчитан на образец без НДС с одной строкой. Если используются НДС или разные правила строк, доработать адаптер под фактический учёт. Не отключать НДС ради прохождения проверки.

### Счета и платежи

1. Выбрать кассу и банковский счёт нужной организации в документах КА2.
2. Проверить банковские реквизиты и суммы в печатном счёте.
3. Подключить подписки на платежи и возвраты по `PAYMENT-METADATA.md`.
4. Проверить распределение оплат по заказам, частичные оплаты, отмену и перепроведение.

### Проведение

Для каждого используемого типа документа выполнить серверный вызов:

```bsl
Профиль = AvtoPultДиагностикаКА2.СформироватьПрофильДвижений(
    СсылкаДокумента
);
```

Проверить проведение и полный откат. Записать результат в `AvtoPultПрофилиПроведения`:

- `PostingProfileId` — идентификатор профиля;
- `ТипДокумента` — `Профиль.documentType`;
- `РегистрыJSON` — JSON массива `Профиль.registers`;
- `SHA256` — `Профиль.sha256`;
- `Проверен` — после успешной проверки;
- `ПроверенВ` — дата проверки.

Подключить вызов `AvtoPultАдаптерКА2.ПровестиДокумент` в сценариях, где требуется автоматическое проведение.

## 5. Проверить и получить `.cfe`

На копии базы выполнить:

1. Заказ → изменение → счёт → PDF.
2. Частичная оплата → полная оплата → возврат.
3. Отмена и перепроведение платежа без двойного учёта.
4. Повтор команды, обрыв связи и перезапуск без дублей.
5. Ошибка печати или проведения с полным откатом.

После исправления ошибок:

1. В Конфигураторе выбрать расширение.
2. Выполнить «Сохранить конфигурацию в файл».
3. Сохранить `C:\Install\AvtoPult.cfe`.
4. Сохранить изменённые исходники и XML-проект отдельно.

Создать контрольную сумму:

```powershell
$cfe = 'C:\Install\AvtoPult.cfe'
$hash = (Get-FileHash -LiteralPath $cfe -Algorithm SHA256).Hash.ToLowerInvariant()
[IO.File]::WriteAllText(
    "$cfe.sha256",
    "$hash  AvtoPult.cfe`n",
    [Text.UTF8Encoding]::new($false)
)
```

## 6. Установить в боевую базу

1. Сделать резервную копию боевой базы и настроек веб-публикации.
2. Открыть:
   «НСИ и администрирование → Печатные формы, отчёты и обработки → Расширения».
3. Нажать «Добавить из файла» и выбрать `AvtoPult.cfe`.
4. Перезапустить сеанс и проверить подключение расширения.
5. Настроить профили и привязки по данным боевой базы. GUID копии автоматически не переносить.

## 7. Опубликовать сервисы 1С

На сервере, который обслуживает браузерный адрес боевой 1С:

1. Открыть Конфигуратор боевой базы.
2. Открыть «Администрирование → Публикация на веб-сервере».
3. Выбрать существующую публикацию.
4. Включить стандартный интерфейс OData.
5. Разрешить HTTP-сервисы расширений и сервис `AvtoPult`.
6. Применить публикацию, сохранив остальные настройки.
7. Создать пользователей:
   - чтение справочников через OData;
   - обмен через HTTP-сервис с правами расширения.
8. Передать технику адрес публикации, логины и пароли.

# Действия на компьютере агента

Все команды выполнять в PowerShell от имени администратора.

## 8. Проверить доступ к боевой 1С

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $base = (Read-Host 'Адрес публикации боевой 1С').TrimEnd('/')
    $readUser = Read-Host 'Пользователь чтения 1С'
    $writeUser = Read-Host 'Пользователь обмена 1С'

    $odata = $base + '/odata/standard.odata/Catalog_ВидыЦен?$select=Ref_Key&$top=1&$format=json'

    curl.exe --fail --silent --show-error `
        --connect-timeout 10 --max-time 60 `
        --user $readUser --output NUL `
        --write-out "OData HTTP %{http_code}`n" `
        --url $odata

    if ($LASTEXITCODE -ne 0) { throw 'Ошибка доступа к OData' }

    curl.exe --fail --silent --show-error `
        --connect-timeout 10 --max-time 60 `
        --user $writeUser `
        --header 'x-avtopult-contract-version: 1.0' `
        --write-out "`nHTTP %{http_code}`n" `
        --url "$base/hs/avtopult/v1/diagnostics"

    if ($LASTEXITCODE -ne 0) { throw 'Ошибка доступа к расширению' }
}
```

Ввести пароли по запросу. При `404` вернуться к публикации сервисов 1С.

## 9. Получить код подключения в СТО

1. Создать реальные СТО и склады в приложении.
2. Открыть раздел интеграции с 1С.
3. Получить код подключения агента.

## 10. Установить агент

Для новой установки:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $zip = 'C:\Install\AvtoPult-OneCAgent-windows-x64.zip'
    $hash = ((Get-Content "$zip.sha256" -Raw -Encoding UTF8).Trim() -split '\s+')[0]
    $base = Read-Host 'Адрес публикации боевой 1С'

    $options = @{
        Archive        = $zip
        ExpectedSha256 = $hash
        ApiUrl         = 'https://cto24.kz/api/v1/'
        OneCBaseUrl    = $base
    }

    if (([Uri]$base).Scheme -eq 'http') {
        if ((Read-Host 'Соединение с 1С идёт по доверенной локальной/VPN-сети? ДА') -ne 'ДА') {
            throw 'Для этого соединения нужен HTTPS'
        }
        $options.AllowLocalHttp = $true
    }

    & 'C:\Install\install-package.ps1' @options
}
```

Ввести логины, пароли пользователей 1С и код подключения СТО.

Если актуальный пакет уже распакован в `C:\one-c-agent`, а служба ещё не установлена:

```powershell
& 'C:\one-c-agent\setup-agent.ps1' -ApiUrl 'https://cto24.kz/api/v1/'
```

Для HTTP в доверенной локальной/VPN-сети добавить `-AllowLocalHttp`.

## 11. Если агент уже работает — обновить вместо переустановки

Распаковать новый пакет в отдельную папку, например `C:\Install\agent-new`, затем:

```powershell
& 'C:\Install\agent-new\update-service.ps1' `
    -NodeExe 'C:\Install\agent-new\runtime\node.exe' `
    -CurrentDirectory 'C:\one-c-agent' `
    -ReleaseDirectory 'C:\Install\agent-new'
```

## 12. Выбрать организацию, склады и цены

```powershell
& 'C:\one-c-agent\configure-mappings.ps1'
```

Выбрать по названиям:

- организацию;
- цену товаров;
- цену услуг;
- закупочную цену;
- склад 1С для каждого склада СТО;
- нормочасы услуги без норматива.

Подтвердить `ДА`. Идентификаторы сохраняются автоматически.

## 13. Проверить агент

```powershell
& 'C:\one-c-agent\diagnose-agent.ps1' `
    -NodeExe 'C:\one-c-agent\runtime\node.exe' `
    -AgentDirectory 'C:\one-c-agent'
```

Проверить отсутствие ошибок и появление подключённого агента в кабинете СТО.

## 14. Включить запись

После завершения проверки специалистом 1С открыть конфигурацию:

```powershell
notepad.exe 'C:\ProgramData\AvtoPult\OneCAgent\agent-config.json'
```

Изменить только:

```json
"ONE_C_ALLOW_WRITES": "1"
```

Сохранить файл и выполнить:

```powershell
Restart-Service AvtoPultOneCAgent

& 'C:\one-c-agent\diagnose-agent.ps1' `
    -NodeExe 'C:\one-c-agent\runtime\node.exe' `
    -AgentDirectory 'C:\one-c-agent'
```

## 15. Контрольный боевой заказ

1. Создать согласованный заказ в СТО.
2. Проверить его появление в 1С.
3. Изменить состав и сверить результат.
4. Выставить счёт и открыть PDF.
5. Провести оплату штатным способом и сверить сумму и статус в обеих системах.

При ошибке вернуть `ONE_C_ALLOW_WRITES` в `"0"` и перезапустить службу. Очередь агента и документы не удалять.
