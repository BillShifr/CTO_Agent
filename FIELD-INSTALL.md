# Выездная установка: текущий этап

## Команда специалисту

Распаковать проверенный Windows release в `C:\one-c-agent`. В PowerShell администратора:

```powershell
powershell -ExecutionPolicy Bypass -File C:\one-c-agent\setup-agent.ps1 -AllowLocalHttp
```

Ввести HTTPS URL API AvtoPult (`/api/v1/`), URL публикации 1С, логины чтения/записи,
одноразовый код из кабинета и непустые пароли 1С. Секрет агента выдаётся автоматически.
`-AllowLocalHttp` разрешает незашифрованный HTTP только для доверенного соединения с 1С;
облако всегда HTTPS. На удалённом VPN-компьютере Radmin остаётся зависимостью.

Мастер проверяет UTF-8 manifest и Node.js, сохраняет конфигурацию штатным защищённым
конфигуратором, проверяет подключения **до запуска службы**, затем устанавливает службу
и проверяет её. Запись выключена. Проверка без установки: добавить `-PreflightOnly`.
Она проверяет пакет/runtime, но не сеть и не 1С.

При ошибке подключения конфигурация сохраняется: исправить причину и повторить команду.
Код повторно не расходуется. Уже установленная служба не изменяется: для неё использовать
`diagnose-agent.ps1` или `update-service.ps1`. Отчёт диагностики выводится без паролей.

## Что ещё не упаковано

- Windows CI включает Node.js 22.20.0 x64 и LICENSE в `runtime/`; отдельная установка не нужна.
- Проверенного `AvtoPult.cfe` нет. Исходники в пакете не являются готовым расширением.
- 404 от `/hs/avtopult/v1/diagnostics` блокирует установку службы; требуется сборка,
  тестовая установка и публикация расширения с нужными правами.
- Сопоставление организаций/складов/цен и нативная приёмка не выполняются мастером.
- Успешная диагностика не доказывает создание заказа, печать, проведение или возврат.

## План готового комплекта

1. Единый запуск и запрет старта при ошибках — реализован, Windows-проверка в CI.
2. Встроенный runtime — реализован, SHA-256 официального ZIP закреплён; проверяется в Windows CI.
3. Готовый XML-проект, сборка `.cfe`, проверка на КА2 2.4.5.21 — не выполнено.
4. Выбор справочников и безопасное включение записи после приёмки — не выполнено.
5. Полный цикл на копии, повтор, обрыв, перезапуск, потерянный ответ — не подтверждено.

Не использовать этот этап как подтверждение готовности к боевой записи.
