# P-13. Блок для специалиста 1С

Цель: подключить СТО к КА2 Казахстан. Исходная целевая версия — платформа 8.3.23.2040,
конфигурация 2.4.5.21. Перед работой сверить фактическую версию и доработки заказчика.
Все изменения сначала выполнить на копии, затем установить проверенный результат в боевую базу.

## 1. Собрать проект расширения

- В Конфигураторе создать расширение `AvtoPult`.
- Создать объекты по `extension-project-manifest.json` и описаниям `*-METADATA.md`.
- Загрузить модули из `src`; имена технических объектов `AvtoPult…` не переименовывать.
- Выгрузить иерархический XML-проект с `Configuration.xml` в корне.
- Собрать `.cfe` по `BUILD-AND-INSTALL.md`; скрипт требует отдельную сборочную базу,
  не использовать боевую для сборки.

В комплекте нет готового проверенного `.cfe`. Скрипт сборки не создаёт недостающие объекты.

## 2. Подключить штатную печать — требуется доработка кода

Точка входа: `src/CommonModules/AvtoPultСчета/Module.bsl`, функция `Создать(Payload)`.
Сейчас новая попытка возвращает `503 PRINT_PIPELINE_NOT_CONFIGURED`.

1. В модуле менеджера `СчетНаОплатуКлиенту` найти штатную процедуру печати и вызываемые
   общие модули конкретной КА2. Передать их исходники разработчику СТО либо подключить вызов самостоятельно.
2. Сохранить существующую проверку запроса и повтор готовой попытки без генерации второго PDF.
3. Для новой попытки вызвать `AvtoPultСчета.Подготовить(Payload)`; при отказе вернуть ошибку.
4. Для полученной ссылки на счёт вызвать штатную печать и получить `ТабличныйДокумент`.
   Не заменять её самостоятельно нарисованным счётом: нужны реальные реквизиты, НДС и банковский счёт.
5. Вызвать `AvtoPultСчета.ПринятьPDF(СсылкаСчета, Payload.requestAttempt, ТабличныйДокумент)`.
6. Вернуть успешный ответ существующего контракта только после состояния `ready` и записи PDF
   в очередь. При ошибке печати весь запрос должен откатываться.

Транзакцией владеет `AvtoPultИнтеграция`: внутренние функции не должны фиксировать её самостоятельно.
Проверить реальный HTTP-путь, а не только ручной вызов `ПринятьPDF`.
Изменения модулей вернуть в репозиторий, чтобы следующая сборка не затёрла исправления.

## 3. Настроить нативные профили — мастер агента этого не делает

### Заказы

1. Создать отдельный непроведённый технический заказ-образец для каждой СТО.
2. Заполнить организацию, подразделение, соглашение, валюту, склад, вид цены,
   правила НДС, хозяйственную операцию и расчётов.
3. В регистре `AvtoPultПрофилиСтанций` связать `StationId` с `ОбразецЗаказа`.
   Флаги `Проверен` и `БезНДСПодтверждено` ставить только после фактической проверки условий.
4. Настроить точные связи клиентов/контрагентов/партнёров и автомобилей в
   `AvtoPultКлиенты` и `AvtoPultАвтомобили` по `ORDER-METADATA.md`.
   Мастер справочников агента эти связи не создаёт.

Текущий код принимает образец с одной строкой без НДС и копирует один вид цены/ставку.
Если боевые операции требуют НДС, разных правил строк или создания новых клиентов/автомобилей,
нужна доработка адаптера. Нельзя отключать реальные налоги или проверки ради успешного запроса.
Также проверить необходимые переходы статусов, не считать наличие профиля поддержкой всех переходов.

### Касса, банковский счёт и проведение

- Выбрать реальные кассу и банковский счёт нужной организации в платёжных документах КА2.
  Проверить заполнение банковских реквизитов в счёте/PDF. Общего окна этих настроек в расширении нет.
- Проверить подписки на платежи/возвраты по `PAYMENT-METADATA.md`: распределения по заказам,
  частичная оплата, отмена и перепроведение должны менять события без двойного учёта.
- Для каждого используемого типа документа получить реальные регистры:
  `AvtoPultДиагностикаКА2.СформироватьПрофильДвижений(СсылкаДокумента)`.
- Проверить проведение и полный откат по `BUILD-AND-INSTALL.md`, затем записать профиль
  в `AvtoPultПрофилиПроведения` по `POSTING-METADATA.md`.
  `Проверен` не ставить до проверки; список регистров не угадывать.
- Если автоматическое проведение требуется в конкретном сценарии, связать его с
  `AvtoPultАдаптерКА2.ПровестиДокумент` и проверенным профилем. Одного заполнения регистра недостаточно.

## 4. Опубликовать обмен и выдать доступы

На сервере веб-публикации 1С, а не на сервере сайта СТО:

1. Сохранить настройки существующей публикации и резервную копию базы.
2. В Конфигураторе открыть «Администрирование → Публикация на веб-сервере».
3. В существующей публикации включить OData и HTTP-сервисы расширений; разрешить сервис `AvtoPult`.
   Сохранить остальные параметры. При ручной публикации IIS/Apache использовать соответствующую
   процедуру установленной платформы; не заменять конфигурацию веб-сервера целиком.
4. Создать пользователей чтения и обмена с необходимыми правами; не выдавать агенту полные права.
5. С компьютера агента проверить чтение справочников и
   `/hs/avtopult/v1/diagnostics` с соответствующими учётными данными.
6. Сообщить технику адрес боевой публикации и передать учётные данные защищённым способом.

## 5. Приёмка и результат работ

На копии выполнить пять сценариев с проверкой документов, движений, сумм и статусов в СТО:

1. Создание и изменение заказа; состав после выставления счёта защищён.
2. Счёт со штатным PDF; реквизиты организации, банка, клиента и суммы верны.
3. Частичная/полная оплата и возврат; отмена/перепроведение не дают двойного учёта.
4. Повтор команды, потерянный ответ, обрыв связи и перезапуск: без потерь и дублей.
5. Ошибка печати/проведения: полный откат документа, движений и событий; исправленный повтор проходит.

Передать `.cfe` с SHA-256, XML-проект, изменённые BSL-модули, заполненные профили и протокол
пяти сценариев. Только после этого установить расширение в боевую базу и разрешить запись агенту.
Не отмечать эти сценарии как PASS по unit-тестам или эмуляции.

## Статус работ

- Агент: выбор организации, складов и видов цен по названиям реализован; команда
  `configure-mappings.ps1`, подтверждение перед записью и контрольное чтение.
- Печать, нативные профили/привязки, применимость и сборка `.cfe`: требуют работы специалиста 1С.
- Нативная приёмка: НЕ ПОДТВЕРЖДЕНА. Этот документ не является разрешением боевого запуска.
