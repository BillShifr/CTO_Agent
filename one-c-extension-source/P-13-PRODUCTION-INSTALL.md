# Подключение боевой 1С к СТО

## 1. Подготовить файлы и доступы

Положить в `C:\Install`:

- `AvtoPult.cfe` — расширение СТО;
- `AvtoPult-OneCAgent-windows-x64.zip` и его `.sha256`;
- `install-package.ps1`.

Потребуются доступ администратора к боевой 1С и её веб-серверу, права администратора
на Windows-компьютере агента и вход владельца в СТО.

## 2. Установить расширение — специалист 1С

1. Сделать резервную копию боевой базы и настроек её веб-публикации.
2. В 1С открыть «НСИ и администрирование → Печатные формы, отчёты и обработки → Расширения».
3. Нажать «Добавить из файла», выбрать `C:\Install\AvtoPult.cfe`, перезапустить сеанс.
   Если расширение уже установлено, выбрать его и нажать «Обновить из файла».
4. Проверить, что расширение подключено без ошибок.

## 3. Создать профили — специалист 1С

В СТО создать реальные станции и склады, записать идентификаторы станций.
Для каждой станции выбрать в боевой 1С заказ с нужными организацией, подразделением,
соглашением, валютой, складом и правилами расчётов. Выбрать строку без НДС с нужным видом цены.

В консоли серверного кода 1С выполнить, заменив номер, год, StationId и номер строки:

```bsl
Источник = AvtoPultНастройкаПрофилей.НайтиДокумент(
    "ЗаказКлиента", "НОМЕР-ЗАКАЗА", 2026);
Результат = AvtoPultНастройкаПрофилей.СоздатьПрофильСтанции(
    "STATION-ID-ИЗ-СТО", Источник, 1);
```

Функция создаёт отдельный технический образец и запись профиля. Повтор с теми же настройками
возвращает существующий образец. Если номер неоднозначен или настройки отличаются, остановиться
и сверить выбранный документ; существующий профиль не перезаписывается.

Открыть `Результат.template`, сверить скопированные настройки и отсутствие проведения.
После подтверждения применимости проверенного сценария без НДС в регистре
`AvtoPultПрофилиСтанций` для этого StationId включить `Проверен` и `БезНДСПодтверждено`.
Если в организации требуется НДС, этот профиль не активировать.

Для каждого используемого сценария проведения выбрать существующий проведённый документ
той же операции. Например, для клиентского поступления наличных:

```bsl
Источник = AvtoPultНастройкаПрофилей.НайтиДокумент(
    "ПриходныйКассовыйОрдер", "НОМЕР-ПКО", 2026);
Результат = AvtoPultНастройкаПрофилей.СоздатьПрофильПроведения(
    "cash-receipt-v1", Источник);
```

Тип, список регистров и хеш сохраняются автоматически. Имя профиля должно совпадать с
именем, используемым вызывающим сценарием. После сверки с результатами нативной приёмки
в `AvtoPultПрофилиПроведения` заполнить `Проверен` и `ПроверенВ`.

Для клиентов и автомобилей заполнить точные связи в `AvtoPultКлиенты` и `AvtoPultАвтомобили`:
идентификатор клиента СТО → партнёр/контрагент 1С; идентификатор автомобиля СТО → автомобиль 1С.
Создание профилей эти связи не создаёт. Сверить кассу и банковский счёт в документах и печатном счёте.

## 4. Включить обмен на сервере 1С — специалист 1С

1. В Конфигураторе боевой базы открыть «Администрирование → Публикация на веб-сервере».
2. Выбрать существующую публикацию, включить OData и HTTP-сервис расширения `AvtoPult`.
3. Применить публикацию, сохранив остальные параметры.
4. Подготовить пользователя чтения справочников и пользователя обмена с правами расширения.
5. Записать адрес публикации боевой базы и учётные данные для установки агента.

## 5. Установить агент — Windows-компьютер СТО

В кабинете СТО открыть интеграцию с 1С и получить код подключения.
Открыть PowerShell от имени администратора:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $zip = 'C:\Install\AvtoPult-OneCAgent-windows-x64.zip'
    $hash = ((Get-Content "$zip.sha256" -Raw -Encoding UTF8).Trim() -split '\s+')[0]
    $base = Read-Host 'Адрес публикации боевой 1С'
    $options = @{
        Archive = $zip
        ExpectedSha256 = $hash
        ApiUrl = 'https://cto24.kz/api/v1/'
        OneCBaseUrl = $base
    }
    if (([Uri]$base).Scheme -eq 'http') {
        if ((Read-Host 'Доступ к 1С идёт по доверенной локальной сети/VPN? ДА') -ne 'ДА') {
            throw 'Укажите HTTPS-адрес публикации 1С'
        }
        $options.AllowLocalHttp = $true
    }
    & 'C:\Install\install-package.ps1' @options
}
```

Ввести логины и пароли чтения/обмена 1С, затем код подключения СТО.
Если пакет уже распакован в `C:\one-c-agent`, но служба ещё не установлена:

```powershell
& 'C:\one-c-agent\setup-agent.ps1' -ApiUrl 'https://cto24.kz/api/v1/'
```

Для HTTP в доверенной локальной сети/VPN добавить `-AllowLocalHttp`.
Работающий агент обновлять из нового пакета, распакованного в `C:\Install\agent-new`:

```powershell
& 'C:\Install\agent-new\update-service.ps1' `
    -NodeExe 'C:\Install\agent-new\runtime\node.exe' `
    -CurrentDirectory 'C:\one-c-agent' `
    -ReleaseDirectory 'C:\Install\agent-new'
```

## 6. Выбрать справочники и проверить соединение

```powershell
& 'C:\one-c-agent\configure-mappings.ps1'
```

Выбрать организацию, виды цен товаров/услуг/закупки, склад 1С для каждого склада СТО
и нормочасы услуги без норматива. Подтвердить `ДА`.

```powershell
& 'C:\one-c-agent\diagnose-agent.ps1' `
    -NodeExe 'C:\one-c-agent\runtime\node.exe' `
    -AgentDirectory 'C:\one-c-agent'
```

Проверить отсутствие ошибок и подключение агента в кабинете СТО.
При `404` на `/hs/avtopult/v1/diagnostics` проверить публикацию на сервере 1С.

## 7. Включить запись и проверить рабочий заказ

После подтверждения настроек специалистом 1С:

```powershell
notepad.exe 'C:\ProgramData\AvtoPult\OneCAgent\agent-config.json'
```

Изменить только `"ONE_C_ALLOW_WRITES": "0"` на `"ONE_C_ALLOW_WRITES": "1"`, сохранить:

```powershell
Restart-Service AvtoPultOneCAgent
```

Создать согласованный рабочий заказ в СТО, проверить его в 1С, изменить состав,
выставить счёт, открыть PDF. При реальной оплате сверить сумму и статус в обеих системах.
При ошибке вернуть `ONE_C_ALLOW_WRITES` в `"0"` и перезапустить службу.
