# Профили проведения

`AvtoPultПрофилиПроведения` — непериодический независимый регистр сведений расширения.
Он хранит только профили движений, подтверждённые на тестовой КА2. Cloud и агент передают
стабильный `PostingProfileId`, но не могут передать или изменить список регистров.

| Поле             | Вид       | Тип                         |
| ---------------- | --------- | --------------------------- |
| PostingProfileId | Измерение | Строка(128)                 |
| ТипДокумента     | Ресурс    | Строка(128)                 |
| РегистрыJSON     | Ресурс    | Строка неограниченной длины |
| SHA256           | Ресурс    | Строка(64)                  |
| Проверен         | Ресурс    | Булево                      |
| ПроверенВ        | Ресурс    | Дата, состав даты и времени |

`РегистрыJSON` содержит только JSON-массив отсортированных имён регистров. `SHA256` считается
для JSON-объекта `{"documentType": <ТипДокумента>, "registers": <массив>}` функцией
`AvtoPultИнтеграция.SHA256`. Запись активируется (`Проверен = Истина`) только после успешной
нативной проверки проведения и полного rollback. Изменение профиля требует повторить эту проверку.

Runtime отклоняет отсутствующий, непроверенный, повреждённый профиль и профиль другого типа
документа до проведения. Внешний HTTP-контракт не предоставляет CRUD для этого регистра.
