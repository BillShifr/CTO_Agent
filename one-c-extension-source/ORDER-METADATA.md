# Метаданные `AvtoPultЗаказы` — FR-INT-001/006

Исходник реализует **непроведённый заказ без НДС**, не проведение, резервирование или все
переходы workflow. Наличие кода не означает проверку платформой. До установки обязательны
создание метаданных расширения, синтаксическая проверка и сценарии на полной тестовой 1С.

Общий модуль `AvtoPultЗаказы`: серверный, неглобальный; экспорт `Применить(Payload)`.
Транзакцию открывает транспорт. Любая ошибка откатывает документ и записи регистров.
Решение не создаёт клиентов по имени/телефону и автомобили по госномеру: использует точные
привязки стабильных `clientId` и `vehicleId`. VIN сохраняется в `PayloadJSON`, а не в
несуществующем реквизите справочника `Автомобили`.

## Независимые непериодические регистры

Все поля ключей — измерения; остальные — ресурсы. Строки ключей имеют длину 128,
числа версий/ключей строк — 10,0, хеш — строка 64. Управляемые блокировки включены.

| Регистр                  | Ключ                    | Ресурсы                                                                                                                                                                                       |
| ------------------------ | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AvtoPultЗаказы`         | `WorkOrderId`           | `ЗаказКлиента` (ДокументСсылка.ЗаказКлиента), `Версия`, `Хеш`, `Версия1С` (строка 128), `StationId`, `ClientId`, `VehicleId`, `PayloadJSON` (неограниченная строка), `СчетВыставлен` (булево) |
| `AvtoPultСтрокиЗаказов`  | `WorkOrderId`, `ItemId` | `КодСтроки`, `Номенклатура` (СправочникСсылка.Номенклатура)                                                                                                                                   |
| `AvtoPultКлиенты`        | `ClientId`              | `Партнер` (СправочникСсылка.Партнеры), `Контрагент` (СправочникСсылка.Контрагенты)                                                                                                            |
| `AvtoPultАвтомобили`     | `VehicleId`             | `Автомобиль` (СправочникСсылка.Автомобили)                                                                                                                                                    |
| `AvtoPultПрофилиСтанций` | `StationId`             | `ОбразецЗаказа` (ДокументСсылка.ЗаказКлиента), `Проверен`, `БезНДСПодтверждено` (булево)                                                                                                      |

`СчетВыставлен` устанавливается модулем счетов в одной транзакции с выставлением счета.
Дополнительно проверяется наличие неаннулированного, неудалённого нативного счета с основанием
заказом. Другие нативные писатели должны соблюдать тот же порядок блокировки заказа; гонка
ручного выставления счета проверяется на тестовой и до этого не считается закрытой.
Реестр строк не очищается при удалении позиций: повторное использование `ItemId` для другой
номенклатуры запрещено. Исходный JSON хранит дополнительные параметры строк и статусы AvtoPult.

## Подготовка профиля на тестовой

1. Создать непроведённый образец заказа для станции с одной строкой без НДС. Проверить
   организацию, подразделение, соглашение, валюту, склад, вид цены, ставку НДС, вариант
   обеспечения, хозяйственную операцию, порядок расчётов и начальный нативный статус.
2. Заполнить точные клиентские/автомобильные привязки и профиль. Только после фактической
   проверки выставить `Проверен` и `БезНДСПодтверждено`. По умолчанию оба флага ложны.
3. Не использовать действующий клиентский заказ как изменяемый шаблон. Шаблон — отдельный
   технический документ с ограниченным правом изменения; он не проводится.

Сейчас профиль задаёт один склад и один вид цены/ставку для всех строк. Смешанные ставки,
разные виды цен товаров/услуг и несколько складов в одном заказе ещё не поддержаны.
Документ заполняется только разрешёнными полями, нативные проверки не отключаются.
Количество, цена, сумма и состав после записи перечитываются: изменение платформой приводит
к откату. Защита от внешних изменений — токен `ВерсияДанных` под блокировкой документа.

## Обязательная приёмка на тестовой — пока НЕ выполнена

- Создать заказ; проверить реквизиты, суммы/точность, отсутствие проведения и движений.
- Повторить команду; повторить ту же версию новым ключом; отправить изменённое тело той же версии.
- Изменить/удалить/добавить строку; проверить стабильный `КодСтроки` и защиту от повторного ID.
- Изменить документ вручную, провести, пометить удалённым, выставить счёт — повторная запись отклоняется.
- Проверить неизвестные привязки, НДС, неподдержанный статус и округление: никаких частичных записей.
- Оборвать связь после записи, повторить команду, перезапустить агент — без дублей документа/строк.

Поддержаны статусы снимка `draft`, `created`, `new` без нативного перехода статуса; остальные
отклоняются. Полноценное создание справочников, проведение, НДС, многостатусный обмен,
подписка на обратные изменения и права расширения требуют отдельной реализации/приёмки.
