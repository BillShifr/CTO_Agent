Проверка подтверждает только наличие базовых объектов и полей, которые использует исходник.
Она не подтверждает алгоритм печати, результат проведения, движения регистров или установку
расширения.

Повторная проверка после обновления конфигурации:

```bash
npm run verify:one-c-metadata -- /path/to/metadata-current.xml
```

Команда читает только XML-схему, не делает запросов к данным и возвращает ненулевой код при
отсутствующем объекте, поле или действии проведения.
